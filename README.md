# FoodRush — Swiggy-style Food Delivery Clone

A responsive food-delivery web application inspired by modern Indian food-delivery UX. This is an educational clone and is not affiliated with Swiggy.

## Features

- Restaurant discovery and search
- Food categories
- Restaurant cards with rating, delivery time and offers
- Popular dishes
- Add/remove items from cart
- Cart total calculation
- Sign-in UI
- Responsive desktop/mobile layout
- React + Vite frontend

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, normally `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Notes

The project currently uses mock restaurant/menu data and remote image URLs. For a production system, add a backend/API, authentication, database, payments, address services, restaurant management, order tracking and secure media handling.
